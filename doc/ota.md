
## **1 OTA协议设计**

OTA过程主要是文件传输的过程.

在设备与云端（或APP）连接的场景下，主要流程为：云端向设备发生升级命令 -> 设备回复可否升级 -> 设备请求升级开始 -> 设备请求数据分片… -> 设备校验完整OTA升级包 -> 设备回应升级结果。

## **2 BKV总表**
| KEY值 | VALUE类型  | VALUE描述                                                                                     |
| ---- | -------- | ------------------------------------------------------------------------------------------- |
| 0x01 | number   | F0FA=OTA，表示进入OTA模式，本数据包的其它KV定义遵循OTA场景下的KV定义，覆盖业务数据帧下的KV定义                                   |
| 0x02 | number   | 时间戳                                                                                         |
| 0x03 | number   | 包流水号                                                                                        |
|      |          |                                                                                             |
| 0xB0 | uint8    | OTA子任务类型<br><br>0x01=升级传输/确认<br><br>0x02=数据分片传输<br><br>0x03=传输完成                            |
| 0xB1 | bytes(N) | 标识本次升级任务ID，最长32字节                                                                           |
| 0xB2 | uint8    | 升级结果<br><br>0x00=升级成功<br><br>0x01=升级失败<br><br>0x02=文件校验错误<br><br>0x03=固件版本已为最新              |
| 0xB3 | number   | 文件大小                                                                                        |
| 0xB4 | number   | 数据偏移量（相对于文件开始位置）                                                                            |
| 0xB5 | number   | 数据长度                                                                                        |
| 0xB6 | bytes(N) | 数据内容                                                                                        |
| 0xB7 | bytes(N) | 文件校验和                                                                                       |
| 0xB8 | uint8    | 文件校验方式： 1-MD5，2-SHA256                                                                      |
| 0xB9 | number   | 数字版本号                                                                                       |
| 0xBA | string   | 版本名称，如 V1.0.1                                                                               |
| 0xBB | uint8    | 错误码：<br><br>0x00=正常<br><br>0x01=失败<br><br>0x02=获取数据分片失败                                     |
| 0xBC | number   | 升级目标，升级丛机本身或丛机子模块，具体数值由业务层定义                                                                |
| 0xBD | bytes(4) | 独立OTA服务器IP                                                                                  |
| 0xBE | uint16   | 独立OTA服务器端口                                                                                  |
| 0xBF | string   | HTTP(S)方式下固件下载地址，最大                                                                         |
| 0xC0 | uint8    | 升级方式：<br><br>0x01=连接当前服务器获取升级文件<br><br>0x02=连接独立的OTA服务器获取升级文件<br><br>0x03=通过HTTP(S)方式下载升级文件 |
